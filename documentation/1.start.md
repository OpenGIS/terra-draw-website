# Getting Started

## Prerequisites

Node.js 24 (CI and deploy both pin `24.18.0`) and npm 11. The site is fully static — no backend, database or environment file.

## Install

Use `npm ci` for a reproducible install matching the lockfile; `npm install` can rewrite `package-lock.json`, which CI's `package-lock` job rejects.

```bash
npm ci
npx playwright install --with-deps chromium   # before running tests
```

## Scripts

| Command             | Runs                                             | Notes                                                    |
| ------------------- | ------------------------------------------------ | -------------------------------------------------------- |
| `npm run dev`       | `vite`                                           | HMR dev server at http://localhost:5173 (HTTP)           |
| `npm run typecheck` | `tsc --noEmit`                                   | `src/**/*` only                                          |
| `npm run build`     | `vite build`                                     | Wipes and rewrites `docs/`                               |
| `npm run lint`      | `eslint src`                                     | Flat config in [`eslint.config.js`](../eslint.config.js) |
| `npm test`          | `playwright test --config=playwright.config.ts`  | Builds and previews the site first                       |

`npm run dev` uses Vite defaults — there is no `server` block — so it serves HTTP on 5173. The geolocation button works locally because browsers treat `localhost` as a secure context; a LAN IP over HTTP would not.

`tsc --noEmit` covers `src/**/*` only, so `vite.config.ts`, `playwright.config.ts` and the Playwright specs are not type-checked. ESLint lints `src/**/*.{js,jsx,ts,tsx}`, ignoring `build/`, `docs/` and `node_modules/`; its unused-vars rule exempts `h`, which every classic-runtime JSX file imports.

## Top-Level Layout

| Path                         | Purpose                                                                  |
| ---------------------------- | ------------------------------------------------------------------------ |
| `index.html`                 | Vite entry; `#app` mount and module script                               |
| `src/`                       | Components, routes, utils, global CSS/theme tokens and assets            |
| `tests/e2e/`, `tests/data/`  | Playwright specs and fixtures, and GeoJSON fixtures — see [Testing](5.testing.md) |
| `.github/workflows/`         | `ci.yml` and `deploy-pages.yml`                                          |
| `vite.config.ts`             | Preact preset; `build.outDir: "docs"`                                    |
| `playwright.config.ts`       | E2E configuration; `tsconfig.json` and `eslint.config.js` hold TS and lint config |
| `CNAME`                      | Repo-root `terradraw.io`; not used by the Actions deploy — the custom domain comes from GitHub Pages settings |
| `size-plugin.json`           | Stale preact-cli artefact, unused (see [Architecture](2.architecture.md)) |
| `documentation/`             | This documentation                                                       |
