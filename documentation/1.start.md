# Getting Started

> Get the site running locally, know which script does what, and find your way around the repo.

## Prerequisites

| Tool    | Version | Notes                                                                                                                            |
| ------- | ------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Node.js | 24      | CI pins `24.18.0` ([`ci.yml:20`](../.github/workflows/ci.yml)); the deploy workflow pins `24.14.1` ([`deploy-pages.yml:29`](../.github/workflows/deploy-pages.yml)) |
| npm     | 11      | `package-lock.json` is lockfile v3; CI uses `npm ci`                                                                            |

There is no backend, database or environment file — the site is fully static and all product behaviour runs in the browser.

## Install

```bash
npm ci
```

Use `npm ci` for a reproducible install that matches the lockfile, exactly as CI does. `npm install` works locally but can update the lockfile, which the CI `package-lock` job will reject.

Playwright's browser is a separate download, only needed before running tests — see [Testing](5.testing.md) for the full testing guide:

```bash
npx playwright install --with-deps chromium
```

## Scripts

| Command             | Runs                                    | Notes                                                          |
| ------------------- | --------------------------------------- | -------------------------------------------------------------- |
| `npm run dev`       | `vite`                                  | Dev server with HMR                                            |
| `npm run typecheck` | `tsc --noEmit`                          | Checks `src/**/*` only (see [Architecture](2.architecture.md)) |
| `npm run build`     | `vite build && echo 'terradraw.io' > docs/CNAME` | Wipes and rewrites `docs/`                            |
| `npm run lint`      | `eslint src`                            | Flat config in [`eslint.config.js`](../eslint.config.js)       |
| `npm test`          | `playwright test --config=playwright.config.ts` | Builds the site and serves it via `vite preview` first |

## Dev Server

`npm run dev` starts Vite at **http://localhost:5173** over **HTTP**.

There is no `dev:http` script and no `server` block in [`vite.config.ts`](../vite.config.ts), so Vite's defaults apply: port 5173, no HTTPS. Older notes claiming port 8080 or an HTTPS dev server are out of date.

> [!NOTE]
> The geolocation button works locally even over HTTP: browsers treat `localhost` as a secure context. A non-HTTPS origin such as a LAN IP would block `navigator.geolocation`.

## Running Tests

```bash
npx playwright install --with-deps chromium   # first time only
npm test
```

[`playwright.config.ts`](../playwright.config.ts) defines:

- `testDir: ./tests/e2e`, Chromium only, `baseURL: http://127.0.0.1:4173` (`playwright.config.ts:14`).
- A `webServer` block that runs `npm run build && npx vite preview --host 127.0.0.1 --port 4173 --strictPort` and reuses an existing server outside CI (`playwright.config.ts:17-22`).
- Retries of 2 in CI, 0 locally (`playwright.config.ts:10`).

The current suite is a single smoke test, [`tests/e2e/production-build-loads.spec.ts`](../tests/e2e/production-build-loads.spec.ts), which loads the production build and asserts the title, header links, Info/GeoJSON tabs and the collapse button. See [Testing](5.testing.md) for the full testing guide.

## Typecheck and Lint

```bash
npm run typecheck
npm run lint
```

`tsc --noEmit` covers only files included by [`tsconfig.json`](../tsconfig.json) (`src/**/*`) — the Playwright config, specs and `vite.config.ts` are outside the program and are not type-checked. ESLint lints `src/**/*.{js,jsx,ts,tsx}`, ignoring `build/**`, `docs/**` and `node_modules/**` ([`eslint.config.js:7`](../eslint.config.js)); the unused-vars rule exempts `h` because every classic-runtime JSX file imports it.

## Top-Level Layout

| Path                     | Purpose                                                                                                   |
| ------------------------ | --------------------------------------------------------------------------------------------------------- |
| `index.html`             | Vite entry; `#app` mount (`index.html:19`) and the module script (`index.html:20`)                        |
| `src/`                   | Application code — components, routes, utils, global CSS and assets                                       |
| `tests/e2e/`             | Playwright specs — see [Testing](5.testing.md)                                                            |
| `.github/workflows/`     | `ci.yml` (lint, lockfile, typecheck, build + test) and `deploy-pages.yml` (GitHub Pages)                  |
| `vite.config.ts`         | Preact preset; `build.outDir: "docs"`                                                                     |
| `playwright.config.ts`   | E2E configuration                                                                                         |
| `tsconfig.json`          | TypeScript configuration (`src` only)                                                                     |
| `eslint.config.js`       | ESLint flat config                                                                                        |
| `package.json`           | Scripts and dependencies                                                                                  |
| `CNAME`                  | Committed copy of `terradraw.io`; the build generates `docs/CNAME` for the deployed branch                 |
| `size-plugin.json`       | Stale preact-cli artefact — not produced or consumed by the current build (see [Architecture](2.architecture.md)) |
| `documentation/`         | This documentation                                                                                        |

> [!WARNING]
> `docs/` does not exist until you build and is **not** the location for developer docs. `vite.config.ts` sets `build.outDir: "docs"`, `.gitignore` ignores `/docs`, and `npm run build` wipes it. Developer documentation lives in `documentation/`.
